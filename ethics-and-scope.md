# Ethics and Scope

This repository is intended for lawful cybersecurity learning, CTF practice, OverTheWire teaching, intentionally vulnerable labs, and systems where explicit permission has been granted.

The material in this repository is for education, skill development, defensive understanding, and responsible security research. It should not be used to access, test, disrupt, scan, exploit, or modify systems without authorization.

## Authorized Learning Environments

Appropriate environments include CTF platforms, intentionally vulnerable virtual machines, local lab systems, OverTheWire exercises, classroom demonstrations, and systems where the learner has explicit permission to test.

## Prohibited Use

The content in this repository should not be used against public systems, third-party networks, employer systems, production systems, cloud environments, applications, or accounts unless explicit authorization has been granted.

## Teaching Philosophy

The goal of this repository is to teach method, reasoning, and defensive understanding. Writeups and notes should explain the process used to solve a problem, the concepts involved, common mistakes, and the defensive lessons that can be learned.

For OverTheWire material, the repository should avoid publishing passwords or bypassing the learning process. Teaching notes should focus on concepts, commands, hints, and reasoning rather than direct answer dumps.

## Defensive Framing

Offensive techniques should be documented with a defensive takeaway. When a lab demonstrates enumeration, credential exposure, misconfiguration, weak permissions, insecure code, or exploitation, the notes should also explain how a defender, administrator, or security engineer could detect, prevent, or remediate the issue.

## Responsible Disclosure

If a real vulnerability is discovered outside of an authorized lab or CTF environment, it should be handled through the appropriate responsible disclosure process. Do not publish exploit details, sensitive data, credentials, or identifying information without authorization.

## Personal Standard

This repository should reflect disciplined, ethical, and professional cybersecurity practice. The goal is to build skill while respecting legal boundaries, platform rules, privacy, and the integrity of systems owned by others.
