# Cybersecurity Learning Lab

Structured cybersecurity learning notes, CTF methodology, OverTheWire teaching material, and defensive takeaways from hands-on labs.

## Start here

Read [ethics and scope](ethics-and-scope.md), then open the [Bandit learning guide index](overthewire/bandit/README.md). Start with the first guide if you are new to the Linux command line.

For each exercise, try the task, explain why a command works, and record the defensive lesson. Use the guide to revisit your reasoning. Work only in an authorized learning environment, and do not publish challenge passwords.

The Bandit guides are available now. The other directories describe areas being developed; they should not be read as a completed course catalog.

Explore my other teaching in [accounting, FinOps, AI, and cloud technology](https://mycalbrown.com/), or visit my [Pluralsight author page](https://www.pluralsight.com/authors/mycal-brown).

## Purpose

This repository documents hands-on cybersecurity learning through CTF practice, Linux command-line exercises, OverTheWire teaching notes, and defensive lessons drawn from offensive security labs.

The goal is not only to record final answers, but to explain the reasoning process, methodology, commands, mistakes, and transferable security concepts behind each exercise.

## Scope

This repository is focused on lawful learning environments, intentionally vulnerable systems, CTF platforms, and labs where explicit permission has been granted.

Planned content includes Linux fundamentals, CTF methodology, OverTheWire teaching material, web security basics, cryptography basics, forensics basics, networking basics, and defensive takeaways.

## OverTheWire Approach

OverTheWire material in this repository is intended for teaching and guided learning. The goal is to explain concepts, commands, and problem-solving methods without publishing passwords or bypassing the learning process.
